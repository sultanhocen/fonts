Fonts

A collection of typefaces maintained for use across software, design, and digital products.

Contents

This repository contains font files organized by family and format. It includes typefaces for interfaces, applications, websites, documents, and other digital environments.

Organization

Fonts are organized into individual directories, with original filenames and supporting documentation preserved wherever possible.

Formats

- TTF
- OTF
- WOFF
- WOFF2

Usage

Browse the directories to locate a typeface. Download the required files and install or integrate them into your project.

Licensing

Each typeface is subject to its respective license. Review the original licensing terms before using, modifying, embedding, or redistributing any font.

Original copyright notices and license files should remain with their respective typefaces.

Maintenance

This repository is maintained and updated as the collection grows. Files are organized to keep the collection consistent and accessible.
